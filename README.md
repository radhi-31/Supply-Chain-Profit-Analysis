# 📦 Supply Chain Profit Analysis Dashboard

## 📖 Overview

This project provides an interactive dashboard to analyze logistics and supply chain operations. It helps businesses monitor sales, profitability, shipping performance, customer segments, and product performance.

---

## 🚀 Features

- 📊 KPI Dashboard
- 🌍 Market Analysis
- 👥 Customer Segment Analysis
- 📦 Product Performance
- 🚚 Shipping Mode Distribution
- 📈 Profit Analysis
- 🔎 Interactive Filters
- 📥 Download Filtered Data

---

## 🛠 Technologies

- Python
- Pandas
- Plotly
- Streamlit

---

## 📂 Dataset

APL Logistics Dataset

---


## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
